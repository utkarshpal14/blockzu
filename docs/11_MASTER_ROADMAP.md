# 1. Purpose

This document defines the complete development roadmap for Blockzu from project setup to public launch.

The roadmap serves as the master guide for:

- Development
- Milestone Planning
- Progress Tracking
- Release Preparation

---

# 2. Development Philosophy

The development process follows:

```text
Build Core Gameplay First
↓
Add Progression
↓
Add Monetization
↓
Polish Experience
↓
Release
```

Priority:

```text
Gameplay > Stability > Monetization > Expansion
```
